## About MicroschoolCoach

MicroschoolCoach is a customizable NextJS theme designed specifically for educators. It provides a simple yet elegant website template for microschools, tutors, educational consultants, and other teaching professionals. This theme includes all the essential components needed to quickly deploy a professional web presence for your educational business.

## Features

- 🎓 Educational resources for microschool creation
- 👩‍🏫 Expert coaching and mentorship
- 🛠️ Tools and templates for school management
- 📊 Business guidance for educational entrepreneurs
- 🤝 Community support for educators

## Tech Stack

- ⚡️ Next.js 13
- ⚛️ React 18
- 📝 TypeScript
- 🎨 Tailwind CSS 3
- 📅 React Calendly integration
- 📱 Responsive design for all devices
- 🔍 SEO optimized
- 🧪 Jest for testing

## Getting Started

### Prerequisites

- Node.js (v14 or later)
- Yarn package manager

### Installation

```bash
# Clone the repository
git clone https://github.com/Cadogy/MicroschoolCoach.git

# Navigate to the project directory
cd MicroschoolCoach

# Install dependencies
yarn install
```

### Development

```bash
# Start the development server
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Building for Production

```bash
# Create a production build
yarn build

# Start the production server
yarn start
```
